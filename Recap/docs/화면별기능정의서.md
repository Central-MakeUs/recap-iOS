# 6. 개발 체크용 핵심 정책

| 구분 | 정책 |
| --- | --- |
| 이미지 선택 | 사용자가 직접 선택한 이미지만 정리 |
| 공유 진입 | 사용자가 OS 공유 시트에서 Recap을 선택한 경우만 진입 |
| 개별 이미지 제거 | 03-02, 04-01에서 X 클릭 시 즉시 제거 |
| 개별 제거 모달 | 사용하지 않음 |
| 선택 이미지 0장 | 정리 시작 버튼 비활성화 |
| 원본 이미지 서버 저장 | 분석 과정에서만 일시 사용, 장기 저장하지 않음 |
| 로컬 원본 미리보기 | 해당 기기에서만 확인 가능 |
| 다른 기기 로그인 | 정리된 캡처 정보는 확인 가능, 원본 미리보기는 제공되지 않을 수 있음 |
| 검색 대상 | 캡처 제목, 한 줄 요약, 핵심 정보, 이미지 속 내용 |
| 검색 표현 | OCR 텍스트, 키워드 같은 기술 표현 사용 금지 |
| 유형 | 9개 중 1개 필수 |
| 보관함 | 유형별/즐겨찾기 탐색만 제공 |
| 로그아웃 | 계정 데이터 삭제 없음 |
| 데이터 삭제 | 계정 유지, 정리된 캡처 데이터 삭제 |
| 회원탈퇴 | 계정과 정리된 캡처 데이터 삭제 |
| 고객 문의 | 외부 메일 앱 실행, 별도 고객센터 화면 없음 |
