- **정의**
    - RE-CAP은 사용자가 다시 보고 싶은 스크린샷을 선택하거나 공유하면, AI가 제목·요약·컬렉션으로 자동 정리해 다시 찾고 활용하기 쉽게 만드는 스크린샷 생산성 앱
- **핵심 Pain Point**
    - 스크린샷 저장은 쉽지만, 저장 이후 다시 찾고 이해하고 활용하는 과정이 번거로워 정보의 활용 가치가 사라진다.
- **MVP 방향**
    - 사용자가 직접 선택하거나 공유한 스크린샷을 자동 정리하는 경험 검증
    
    | 구분 | 내용 |
    | --- | --- |
    | 입력 방식 | 앱 내 선택 업로드, 캡처 직후 공유, 갤러리 공유 |
    | 계정 | 유저별 캡처 데이터 저장을 위해 간편 로그인 포함 방향 |
    | 자동 정리 | OCR/AI 분석을 통해 제목, 요약, 컬렉션 생성 |
    | 확인 필요 | AI 정리 결과가 불확실한 캡처는 사용자가 확인/수정/저장 |
    | 탐색 | 홈, 컬렉션, 검색 |
    | 상세 관리 | 원본 확인, 제목/요약/컬렉션 수정, 삭제 |
- **MVP 포함/제외 범위**
    
    
    | 포함 | 제외 |
    | --- | --- |
    | 선택 업로드 | 자동 업로드 |
    | 공유하기 전송 | 백그라운드 자동 감지 |
    | 간편 로그인 | 개인 컬렉션 생성 |
    | OCR/AI 자동 정리 | 이미지 자체 검색 |
    | 제목/요약/컬렉션 생성 | AI 재분석 |
    | 확인 필요 플로우 | 메모/태그 |
    | 검색/컬렉션/상세 | 팀 공유 |
