# RE-CAP 화면 정의서 v1.1

## 0. 문서 목적

- RE-CAP MVP의 화면 범위를 정의하는 기준 문서
- 와이어프레임 제작, 디자인 파일 정리, 클로드 화면 생성 요청, 개발 화면 누락 체크에 사용

---

## 1. 화면 구성 기준

| 항목 | 최종 기준 |
| --- | --- |
| 하단 탭 | 홈 / 정리하기 / 보관함 |
| 핵심 단위 | 정보카드 |
| 첫 사용 | 온보딩에서 첫 스크린샷 정리 시작 유도 |
| 업로드 방식 | 선택 업로드 / 공유하기 진입 |
| 검색 | 홈에서 진입하는 별도 화면 |
| 보관함 | 즐겨찾기와 유형별 카드 탐색 |
| 설정 | 마이페이지가 아닌 설정 화면 |
| 로그인 | MVP 제외 |
| 소셜 로그인 | MVP 제외 |
| 목적형 컬렉션 | MVP 제외 |
| 확인 필요 화면 | MVP 제외 |
| 자동 업로드 | MVP 제외 |

## 2. ID 부여 기준

| 구분 | ID 형식 | 예시 | 설명 |
| --- | --- | --- | --- |
| 기본 화면 | `영역ID-화면번호_화면명` | `02-01_홈` | 실제 앱 화면 |
| 상태 화면 | `S-영역ID-번호_영역_상태명` | `S-02-01_홈_카드 없음` | 별도 디자인이 필요한 빈 상태/실패 상태 |

| 모달 | `M-영역ID-번호_모달명` | `M-07-01_카드 삭제 확인` | 확인/취소/삭제 등 팝업 |
| 바텀시트 | `B-영역ID-번호_바텀시트명` | `B-07-01_유형 선택` | 하단 선택 UI |
| 컴포넌트 | `C-번호_컴포넌트명` | `C-01_정보카드 리스트 아이템` | 반복 사용 UI |
